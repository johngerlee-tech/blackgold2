## 🌟 專案核心特色亮點

### 1. 🌿 全面套用教育部楷書規範「芫荽體 (Iansui)」與右側直排注音系統
- **芫荽體 (Iansui) 官方字型**：
  - 引入教育部標準楷書筆順規範之「芫荽體」，字體端正、硬筆結構優美，極為適合國中小與低年級學童認讀。
- **標準台灣國字右側直排注音 (Right-Side Vertical Bopomofo)**：
  - 台灣標準國小教科書排版：國字在左，注音符號直排垂直堆疊於右側。
  - **精準四聲調號定位**：
    - 二聲（ˊ）、三聲（ˇ）、四聲（ˋ）精準坐落於直排注音右側上方，並保留獨立間距，絕不與下一個國字碰撞。
    - 輕聲（˙）精準置於注音本體正上方。
    - 聲調採高對比亮橘紅色（`#d84315`），四聲符號標註清清楚楚，一目了然！
  - **全站全面注音化覆蓋**：
    - 包含首頁登入頁面（「黑金魔法術🔮」、導師的話、姓名/班級/座號）。
    - 「🧙‍♂️ 選取你的 RPG 守護英雄」選角頁面（英雄名稱、稱號、被動技能、故事介紹）。
    - 關卡引導說明頁面（第一關至第三關情境介紹）。
    - 戰鬥中題目、四個選項按鈕、錯題檢討投影簡報。
  - **符號規範維護**：
    - 標點符號、數字（0-9）、英文字母代號（A, B, C, D）維持原樣不加注音。
    - 內建 1000+ 完整教育部字典庫與破音字詞庫（長成、熟成、音樂、快樂、芫荽等），100% 離線純代碼直出。

### 2. 🖥️ 1366*768 單螢幕無捲軸雙欄對戰排版（一目了然無需滾動）
- **單螢幕無捲軸精確佈局 (Zero-Scroll Layout)**：
  - 特別針對學校教室常見的 **1366*768 筆記型電腦與觸控一體機** 進行緊緻化優化（`height: calc(100vh - 54px); overflow: hidden;`）。
  - 無需滾動滑鼠滾輪，戰鬥舞台、對陣衝撞、即時血量、題目本文與 ABCD 選項按鈕同時完整呈現。
- **DIV 圖層懸浮精靈舞台 (Floating Sprite DIV)**：
  - 英雄與關主之對戰圖片改用專屬的 `position: absolute` DIV 懸浮圖層呈現。
  - **高度完全獨立**：無論老師或學生上傳何種長寬比例、任何解析度的角色圖片，皆由外層舞台嚴格約束，絕不撐高排版方塊的高度，徹底消除捲軸晃動！
- **題目後方紅色懸浮答對/答錯標籤 (3秒自動淡出)**：
  - 作答後不再於題目下方堆疊冗長佔空間的文字解答。
  - 答對時於題目右側飄起紅色亮眼懸浮標籤 **「✨ 答對了！」**，答錯時飄起 **「💥 答錯了！」**。
  - 動態展示 2.2 秒後淡出，約 3 秒自動隱藏，維持畫面清爽乾淨。

### 5. ⚔️ 對陣戰鬥聲光震撼特效（飄移衝撞、血光受創、返回原位）
- **高速飄移衝刺撞擊（Dash & Clash）**：
  - 英雄攻擊：學生答對時，英雄伴隨呼嘯音效高速前衝猛烈撞擊關卡妖怪。
  - 妖怪反撲：學生答錯時，關卡領主咆哮並高速撲向英雄進行衝撞反擊。
  - 角色撞擊後順滑彈回守備戰鬥座，動作流暢俐落。
- **血光與全景震動（Blood Flash & Screen Shake）**：
  - 撞擊瞬間觸發金屬碰撞與血光音效，受擊方劇烈顫抖泛起血光，戰鬥舞台劇烈震動。
- **浮動傷害數字（Damage Popup）**：
  - 受擊時上方飄起跳動傷害數字（`💥 -100`，`💔 -20`）。
- **獨立分開雙血條（HP）**：
  - 左側英雄血條（綠/黃/紅動態監控）與右側關卡領主大型血條（紫色/紅色）。

## 🚀 如何啟動與部署

### 本機立即執行：
1. 直接在 Windows 檔案總管中雙擊開啟 `index.html`。
2. 無需安裝 Node.js 或任何環境，全純前端架構。

### 部署至 GitHub Pages：
1. 於 GitHub 建立名為 `blackgold2` 的儲存庫。
2. 將本專案推送至 GitHub（指令見 [FIREBASE_SETUP_GUIDE.md](file:///C:/Users/User/.gemini/antigravity/scratch/blackgold2/FIREBASE_SETUP_GUIDE.md)）。
3. 於 Settings ➔ Pages 啟用 `main` 分支。
4. 網址即為：`https://johngerlee-tech.github.io/blackgold2/`
